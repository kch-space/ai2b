# 后续开发与接入路线图

更新日期：2026-11-28。[返回项目介绍](../README.md)

这是后续计划，不代表功能已交付，也不授权执行真实通知、模型调用、数据库清理或公网部署。实施阶段与预警严重级别 P0/P1 是不同概念。

## 当前起点

- 已实现：BTC/ETH 采集/图表、固定价格规则、事件/history/outbox、紧凑 Web 与设置、Telegram 服务端接入、手动 AI 测试/事件报告。
- 已验证：后端 83 项、前端 99 项自动测试及构建；H2、模拟 provider、本机 HTTP/浏览器配置联调。
- 未完成验收：真实 MySQL V4/V5、Telegram 送达、模型回复、长期稳定性。M1 代码闭环已具备，不能据此宣称完整 P0 或生产可用。

## A. 真实环境验收（下一步优先）

| 工作 | 前提与边界 | 验收结果 |
| --- | --- | --- |
| MySQL V4/V5 迁移 | 先备份，正常启动 Flyway；不重新建库、不覆盖旧迁移 | 迁移/校验通过，已有行情保留，重启后配置与队列可读 |
| 加密主密钥恢复 | 数据库和主密钥分别备份；不将密钥写 Git/聊天 | 恢复后解密成功；丢失/错误主密钥明确失败，不覆写旧配置 |
| 长期行情与预警 | BTC/ETH、地区/网络限制可见；补录不误报 | 连续窗口/缺口/陈旧/重启行为符合规则，记录限流与采集延迟 |
| Telegram 实测 | 用户确认 Token、Chat ID、测试发送及启用 | getMe 身份正确，message_id 与目标消息可核对，停用/换目标取消旧任务 |
| AI 实测 | 用户选择允许的服务商/模型，确认数据范围与费用 | 连接/回复/事件报告成功；错误、超时、费用与报告局限可见 |

真实调用失败不得切换模拟数据后宣称成功；发送结果未知先人工核对，不能盲目重发。验收记录写入 DEVELOPMENT.md，区分测试成功、服务商接受与用户确认收到。

## B. 安全、通知与运行质量

| 待开发项 | 当前限制 | 交付要求 |
| --- | --- | --- |
| 完整认证与会话 | 仅本机来源/同源请求保护，不是用户认证 | 安全密码哈希、会话/CSRF、失败限流、配置写审计；完成前不开放远程 |
| 通知管理 | DEAD 仅展示/审计，无人工重试接口 | 人工核对后明确确认重试，保留原错误与尝试链；未知结果防重复策略 |
| MOCK 显示/运行策略 | Telegram 启用后仍保留 MOCK，不能自动隐藏/关闭 | 可选默认隐藏模拟记录、按需查看；若关闭创建须单独定义策略，不能删除历史 |
| 监控与部署 | 基础健康检查，尚无生产压测/部署验收 | 采集延迟、outbox 年龄/积压、失败、磁盘、密钥恢复、部署/API 文档 |
| 多实例/任务模型 | 采集仍按单实例运行；部分门控是内存状态 | 有实际部署需求再补租约/分布式一致性；不默认现有代码支持多实例 |

## C. 完善 P0 业务

1. **自选与采集范围：** 自选持久化、分组/优先级、取消采集策略；扩展币种前评估配额、数据库容量及压力。
2. **ticker / 更多行情：** 明确实时与闭合口径、REST/WS 补偿与陈旧状态；不能把合约元数据当作已采集行情。
3. **规则编辑/版本切换：** 创建/停用/参数校验、不可变版本、作用域与预热、事件证据追溯；旧事件和 outbox 处理策略明确。
4. **其他规则：** RVOL、OI、费率及组合规则，先补精度/单位/窗口/UNKNOWN 单测，再接入事件闭环。
5. **完整验收：** 真实数据、规则、事务、认证、通知、压测、恢复共同验收；现有测试数量不等于完成度百分比。

## D. 可选集成与分析扩展

| 接入 | 依赖 | 约束 |
| --- | --- | --- |
| Telegram Bot 查询 | 通知渠道验收、认证/接收人白名单 | 当前只会发消息，没有命令、webhook 或 long polling；新增查询需命令权限/限流 |
| 更多 AI 服务商 | 后端主机白名单、兼容性与费用验证 | 当前单配置 OpenAI-compatible；不默认所有服务支持 models/temperature/max_tokens |
| 本地/内网模型 | 部署策略与地址安全评估 | 当前仅显式回环地址；内网域名/任意代理不是既有能力，不能放开 SSRF 检查兜底 |
| 自动/异步 AI 报告 | 手动分析验收、任务去重/费用预算/超时隔离 | 当前同步手动调用；自动化必须单独授权，不能阻塞实时预警 |
| 历史效果统计/回测 | 事件版本/首次证据、成熟样本定义 | 不用未来数据，不把评分当胜率，不宣称收益 |
| 现货、成交/CVD、订单簿、链上 | 数据源授权、地区、成本与可信度 | 明确不可用/不支持；链上标签和持仓方向不得作确定性推断 |
