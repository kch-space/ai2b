# 数据口径与分析模式

## 币安 USDT 永续

只使用 `https://fapi.binance.com`。接口属于币安 USDⓈ-M Futures REST API；筛选交易所元数据中 `contractType=PERPETUAL`、`status=TRADING` 且报价与保证金币种均为 USDT 的交易对。

| 接口 | 字段与用途 |
| --- | --- |
| `/fapi/v1/exchangeInfo` | 合约类型与交易状态，缓存 1 小时 |
| `/fapi/v1/ticker/24hr` | `lastPrice` 最新成交价、24 小时涨跌、成交额、`closeTime`；用于报价与到价提醒 |
| `/fapi/v1/premiumIndex` | `markPrice` 标记价、`indexPrice` 指数价、`lastFundingRate` 当前资金费率、`nextFundingTime` 下一次结算与 `time` |
| `/fapi/v1/klines` | 合约成交价 K 线；丢弃未收盘数据，缓存 60 秒；EMA/RSI/ATR 等基于这些数据 |
| `/fapi/v1/openInterest` | 未平仓合约量与 `time`，USDT 线性合约以基础资产数量展示，缓存 30 秒；只展示水平，不宣称资金流入或流出 |

报价默认 15 秒轮询，最新成交价与标记价各自保留时间戳；生成计划时超过 90 秒或最近 K 线存在缺口则暂停新增仓位。交易所价格、标记价、指数价并非同一概念，不能用某个交易所界面的任意数字直接比较。

资金费率以接口小数值读取，网页转换为百分比；例如 `0.0001` 显示 `0.0100%`。正费率通常为多头支付空头。结算时间读取接口，不假设所有币种固定 8 小时结算。按当前费率与计划名义仓位展示一次结算估算，不保证未来费率或实际持仓成本。

网络或地区错误明确报错，不进行跨交易所或跨市场替换。演示模式需要手动开启，合成价格、标记价、费率与持仓量均明确标注，且不获取或虚构真实新闻。

## 规则报告与 AI 报告

规则报告计算技术指标、多空观察和资金约束，未经过收益回测，不代表胜率或可靠买卖信号。AI 模式必须配置模型（本地模型可无密钥）；远程模型需地址、模型名和密钥。规则模式即使配置了 AI 也不调用模型。

新闻只来自 CoinDesk / Cointelegraph 最近 24 小时 RSS 标题和摘要。币种别名与市场背景关键词匹配后最多取 8 条，按时间倒序排列，每条保存来源、链接、发布时间和引用 ID。缓存 5 分钟；失败、部分失败和没有匹配内容分别标注，不以旧缓存或模型知识伪装新事件。不读取用户自定义 URL，链接限于新闻源自身 HTTPS 域名。

AI 接收同一份技术报告、合约衍生数据和新闻快照，分别输出概述、看多/看空依据、补充观察和事件判断，并引用本次新闻 ID。未提供的新闻 ID 会被拒绝；无有效新闻引用时仅标注技术解读。程序无法证明模型每句话都真实，仍需核对报道原文。RSS 是不可信外部文本，提示词明确禁止遵循其中的指令。

模型不能覆盖程序的价位、信号与仓位金额。AI 模式调用失败时任务报错，不保存替代的规则报告；已有历史报告仍是旧报告，不表示本次成功。

## 资金与时效

金额来自人工账户权益、杠杆和持仓记录。名义仓位、初始保证金估算与单笔风险预算分开展示。未读取账户维持保证金档位、全仓/逐仓、抵押物和强平价，不提供精确爆仓预估；当前每币种只支持一个净持仓。

报告 5 分钟后过期；修改风险设置或持仓也会使仓位计划失效。页面保留历史判断，但隐藏过期计划金额。历史报告与 Telegram 消息是生成时的快照，不会随着行情更新。
