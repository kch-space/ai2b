## 页面结构

| 页面 | 地址 | 内容 |
| --- | --- | --- |
| 概览 | `/#/` | BTC/ETH 两张重点卡片、统计摘要、最多四条活动预警、数据/通知状态 |
| 合约市场 | `/#/markets` | 全量元数据按需搜索/筛选；默认每页 10 条，可选 25/50，长表格内部滚动 |
| 行情详情 | `/#/market/BTCUSDT`、`/#/market/ETHUSDT` | 原有 K 线、成交量及市场指标；返回独立市场页 |
| 事件中心 | `/#/alerts` | 规则状态、分页事件、证据、history、MOCK/Telegram 通知与手动 AI 报告 |
| 设置 | `/#/settings` | 显示偏好、Telegram、AI 模型、系统/规则四个分区，可通过子路由直接打开 |

侧边栏在窄屏改为顶部导航。后端健康检查折叠至顶栏；只能证明应用可访问，不代表数据库、行情采集或通知正常。

概览只读取一条合约元数据获得总数，不将完整合约列表放到首页。每个数据流独立处理失败；刷新失败保留上次成功数据并标注。闭合价格不是实时 ticker，1h 变化率用完整窗口首根开盘价与末根收盘价；存在缺口或陈旧时不计算变化率、不连接趋势线。没有行情时显示空态，不使用模拟行情兜底。

## 可用偏好

保存在当前浏览器 `localStorage` 的 `ai2b.ui-preferences.v1`，持久化字段仅 `version`、`refreshSeconds`、`marketPageSize`：

- 概览读取间隔：15 / 30 / 60 秒，默认 30 秒。
- 合约市场每页数量：10 / 25 / 50，默认 10。
- 返回概览或重新进入市场后应用；不改变后端采集或检测周期。
- 固定 Asia/Shanghai 显示时间，数据仍按 UTC 存储。
- 提供清除本地偏好与旧草稿按钮；存储被禁用时显示真实失败。旧 Telegram/AI 草稿不再读取，保存显示偏好时会丢弃；清除本地数据不会删除服务端集成配置或加密凭据。

## Telegram / AI 服务端设置

已接入后端加密保存及真实连接/测试接口，不再使用浏览器集成草稿。Telegram/AI 默认关闭，测试按钮在密钥已保存且无未保存修改时可用，每次必须确认外部请求/接收目标/费用。

Telegram 支持先只保存 Token，打开机器人发送 `/start`，再点“从 /start 获取 Chat ID”。获取需联网确认，候选显示会话名称/类型/时间/ID；选择仅填入表单，核对后再次保存，不自动启用。手填仍保留，无 Chat ID 时禁用测试发送，空结果与 webhook 冲突均有提示。

保存时显示二次确认，Token/API Key 不回显，输入留空保留已有值，可明确删除；提交后或离开页面清空明文输入，不存 localStorage；清空输入不等于删除后端加密凭据。每个集成支持刷新配置和近期审计；版本冲突需刷新后处理。

Telegram 启用后为符合配置的新预警增加真实发送队列，仍保留 MOCK；页面显示 Telegram + MOCK，不会自动隐藏/删除模拟记录，当前没有相应开关。AI 是按需测试与事件研究，不自动扫描、不阻塞规则。通知记录区分 MOCK/SIMULATED 与 TELEGRAM/SENT/CANCELLED/DEAD。详情页 AI 研究先展示目标模型和事件证据范围，生成报告持久化，按纯文本显示，模型输出需核实。

系统/规则仍仅默认参数说明，不提供规则编辑或采集运行开关。服务商白名单只能在后端设置，本机接口防跨站不等于公网用户认证。完整使用、安全与未验证范围见 [集成说明](INTEGRATIONS.md)。
